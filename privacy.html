Privacy policy

Last updated 17 November 2026

The lab pages

The labs on this site run Python in your own browser. They have no accounts, no forms, no cookies, no analytics and no tracking. The code you type is never sent anywhere. The page loads the Pyodide runtime from cdn.jsdelivr.net, which sees a normal web request.

The CS Motion channel tool (Google sign-in)

CS Motion uses a private tool, run by the channel owner on their own computer, to publish and manage the channel's own YouTube videos. Only the channel owner signs in to it. It asks Google for these permissions and uses them only as described:

  • YouTube upload and management: upload the channel's videos as private for review, set thumbnails, captions, playlists and publish times, and read the comments on the channel's own videos so the owner can answer them.
  • YouTube Analytics (read-only): read view counts, watch time, audience retention and traffic sources for the channel's own videos, to improve future videos.
  • Google Calendar, only calendars the tool created: keep a release calendar of upcoming videos. It cannot see any other calendar.

The data stays on the owner's computer, in local files and a private project log. It is not sold, shared, transferred to third parties or used for advertising, and it is not used to train AI models. Comments read from YouTube are only used to reply to viewers and to choose topics. The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The YouTube features use the YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Deleting the tool's local token file also ends its access.
